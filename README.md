# Finger Counting and Inter-Hand Distance Measurement

A Python project that recognizes raised fingers and measures distances between hand landmarks using a webcam.

## Features
- Detect hands through a webcam
- Recognize raised fingers
- Measure distances between selected hand landmarks

## Technologies
- Python
- OpenCV
- CVZone

## How to Run
1. Install the required dependencies.
2. Connect or enable a webcam.
3. Run the main Python script.

## Project Context
Developed as part of a Python programming course.
